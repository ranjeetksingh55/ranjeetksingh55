## 🚀 Featured Projects

### 🔹 GreenKart Selenium TestNG Framework
End-to-end automation framework for GreenKart web application using Selenium WebDriver + Java + TestNG + POM architecture.

**Tech Stack:** Java 17, Selenium WebDriver 4, TestNG, WebDriverManager, ExtentReports, GitHub Actions, Maven

**Key Features:**
- Page Object Model (POM) architecture
- Data-driven testing with config.properties
- Cross-browser support (Chrome, Firefox)
- Screenshot capture on failure
- Extent HTML report generation
- Retry logic with IRetryAnalyzer (auto-applied via IAnnotationTransformer)
- GitHub Actions CI/CD execution

[View Repository](https://github.com/ranjeetksingh55/greenkart-selenium-testng-framework)
